# SmartCart E-Commerce Dashboard

## 📊 Project Overview

SmartCart E-Commerce Dashboard is an interactive data visualization project built using Python, Dash, Pandas, and Plotly.

The dashboard provides useful insights into sales performance, revenue, customers, products, regions, and payment methods through interactive charts and filters.

## 🚀 Features

* Total Revenue
* Total Orders
* Total Customers
* Total Profit
* Units Sold
* Monthly Revenue Trend
* Revenue by Product Category
* Revenue by Region
* Revenue by Product
* Orders by Payment Method
* New vs Returning Customers
* Top 10 Customers by Spending
* Category filter
* Region filter
* Payment Method filter
* Date Range filter
* Dynamic KPIs and charts based on selected filters

## 🛠️ Technologies Used

* Python
* Pandas
* Dash
* Plotly
* HTML/CSS

## ⚙️ Installation

Create and activate a virtual environment, then install the required packages:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Dashboard

Run the following command from the SmartCart Dashboard folder:

```bash
python app.py
```

Then open the dashboard in your browser:

```text
http://127.0.0.1:8050/
```

## 📈 Dashboard Insights

The dashboard allows users to analyze e-commerce performance interactively. Users can filter the data by category, region, payment method, and date range. The KPIs and visualizations automatically update according to the selected filters.
